# KW-002 — LEVEL 1 CLIENT INTAKE AND SCOPE RULE

Status: **ACTIVE / OWNER-AUTHORIZED SCAFFOLD**

## 1. Minimum required client inputs

The client should not be required to perform SEO research before ordering a semantic-core service.

Minimum intake:

```text
1. What the business sells / what services it provides.
2. Actual assortment or service list.
3. Promotion geography / sales region.
4. Primary commercial action expected from the site.
5. Important inclusions/exclusions and business boundaries.
6. Site state: existing URL or NEW_SITE / SITE_NOT_EXISTS.
```

For a store, acceptable assortment inputs include one or more of:

```text
catalog / price list / XLSX / CSV
marketplace storefront or product links
product/category list
structured owner description of the actual range
```

For services:

```text
service list
service descriptions
geographic/operational boundaries
```

## 2. Optional but useful inputs

```text
client-supplied competitors
existing semantic core
existing page/category ideas
priority products/services
brand vocabulary
Webmaster/Metrika exports or read access
known seasonal/business constraints
```

Optional inputs are context, not automatic truth.

Client-supplied competitors must still be checked against actual current Yandex results before being called search competitors.

Existing semantic cores or prior SEO reports must not become hidden baseline truth in a FROM_SCRATCH order. If accepted for comparison, they are opened only under an explicit later comparison/revision mode after the new baseline is frozen.

## 3. Scope freeze before research

Before Step 1 begins, freeze:

```text
business description
region
assortment/service boundary
commercial goal
known exclusions
site state
allowed client inputs
optional inputs actually supplied
private-access state
order-specific scope / delivery promise
```

Do not edit the frozen brief merely because provider evidence later makes another formulation look more convenient.

Real client corrections are versioned as revisions.

## 4. Clean test rule

When an existing internal project is reused as a greenfield rehearsal:

```text
PRIOR ANALYTICAL RESEARCH = SEALED
```

Allowed before final freeze:

```text
minimum client-like business facts
raw/current assortment facts
owner-supplied business constraints
```

Forbidden before final freeze:

```text
prior Wordstat conclusions
prior Search/Alice findings
prior semantic clusters
prior competitor conclusions
prior opportunity maps
prior page architecture
prior content/page-job decisions
```

After the new result is frozen, prior research may be opened only for an explicitly separated regression/comparison stage.

## 5. No fake client sophistication requirement

Do not require the client to supply:

```text
perfect page list
perfect competitors
keyword list
search intent labels
SEO structure
content clusters
```

Those are part of the work being sold.
