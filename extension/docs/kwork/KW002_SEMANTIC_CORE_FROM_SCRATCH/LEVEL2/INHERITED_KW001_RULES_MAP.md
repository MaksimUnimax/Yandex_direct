## Cross-step rules transferred

```text
DO NOT REFLEXIVELY AGREE WITH ANALYTICAL OBJECTIONS

PRE-STEP METHOD/EVIDENCE REVIEW REQUIRED
PROVIDER SUCCESS != PROJECT EVIDENCE COMPLETION

UNIVERSAL RULES MUST NOT ABSORB JOB-SPECIFIC VALUES
PROJECT METHOD DOES NOT PROVE ITSELF

ONE CURRENT CANONICAL TRUTH FEEDS CLIENT ARTIFACTS
CLIENT ARTIFACT CORRECTNESS != RECIPIENT USABILITY
```

## Rules intentionally NOT copied unchanged

Existing-site-specific methods are not transplanted as-is when the greenfield product has no current site topology, for example:

```text
current-site crawler/topology completeness gates
current URL existence/freshness as a mandatory architecture input
existing-page structural-change tickets
historical competing-page diagnosis requiring private owned-site history
implementation-ready site-edit placement instructions
```

Where the same failure class matters, KW-002 converts it into a future-page/greenfield equivalent rather than pretending an existing site exists.
