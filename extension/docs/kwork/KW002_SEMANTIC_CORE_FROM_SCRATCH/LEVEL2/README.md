# KW-002 — LEVEL 2

Status: **ACTIVE DRAFT / OWNER REVIEW REQUIRED BEFORE EXECUTION**

Level 2 contains **rules and methodology of concrete KW-002 roadmap steps**.

It does not contain Blood & Sand or another order's concrete queries, URLs, counts or evidence. Those belong to `work/<JOB_ID>/`.

## Authorities

```text
STEP_RULES_INDEX.md
= roadmap/navigation: which step exists and what it produces

INHERITED_KW001_STEP_RULES.md
= actual reusable step rules transferred from KW-001, including WHY / failure / control / PASS

future STEP_<N>_*_METHOD.md
= dedicated deeper method when a KW-002 step requires more detail or new external-method validation
```

Hard rule:

```text
"INHERITED FROM KW001" LABEL ALONE != RULE TRANSFER
```

A reused rule must exist in executable substance inside KW-002 permanent documentation; the analyst must not rely on memory or silently reopen KW-001 during execution to discover what the rule meant.

Before executing a step:

```text
READ KW002 LEVEL1
→ READ STEP_RULES_INDEX
→ READ INHERITED_KW001_STEP_RULES section for the current step
→ READ dedicated KW002 step method if one exists
→ READ current work/<JOB_ID>/ state/evidence
→ run required current external-method review
→ owner pre-step explanation/authorization
→ execute
```

Any change to an inherited owner-locked rule requires explicit owner authorization.
