5. DECISION MODEL FOR EACH OF THE 1548 TARGETS
======================================================================

Every target must be assigned through the following ordered reasoning.

### 5.1 First question — is the wording itself an independently meaningful semantic direction?

If NO:
- do not keep wrapper/copy as candidate;
- derive a compact candidate only when a minimal reproducible transformation is justified;
- otherwise OUT_OF_SCOPE or AMBIGUOUS.

### 5.2 Second question — is the underlying referent/business direction in scope?

Use:
- frozen 76-product assortment;
- allowed generic business category: amulets/charms/talismans and relevant automotive variants;
- legitimate informational support around symbols/products/use cases that plausibly help users understand/choose those in-scope products.

Do NOT infer sale of unrelated product classes.

### 5.3 Third question — page wrapper vs semantic concept

Common wrapper classes:
```text
Ассоциации к слову X
Значение слова X
Что такое X — ...
X — это ...
X цена и фото
X ручной работы
X в наличии
overspecified marketplace listing titles
dimensions / condition / seller fluff
bibliographic or site-brand wrapper
```

Rules:
- wrapper text itself should not survive if the useful semantic object is a smaller phrase;
- derive the smaller object only if it is explicit, reproducible and independently meaningful;
- derived phrase must be reconciled against the complete 2172-candidate universe and accepted upstream semantic universe;
- do not invent a query that is not supported by the source wording.

### 5.4 Fourth question — claim language

Competitor claims such as:
```text
привлекает богатство
обеспечивает защиту
приносит удачу
```
may be evidence that competitors/users discuss that concept.

They are NOT client facts and NOT proven effects.

A claim-bearing title can yield a compact use-case/topic candidate only if:
- the resulting formulation is independently meaningful;
- derivation is explicit;
- it remains within the frozen business theme;
- no efficacy truth is asserted.

### 5.5 Fifth question — source multiplicity


Source multiplicity is:
