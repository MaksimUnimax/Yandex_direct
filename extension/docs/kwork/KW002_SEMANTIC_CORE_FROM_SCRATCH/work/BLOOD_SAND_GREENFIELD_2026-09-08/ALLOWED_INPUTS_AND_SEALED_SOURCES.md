# KW-002 Blood & Sand — ALLOWED INPUTS AND SEALED SOURCES

Status: **FROZEN PRE-EXECUTION SOURCE BOUNDARY / OWNER REVIEW PENDING**

## 1. Purpose

The Blood & Sand rehearsal must prove that KW-002 can build a semantic core and site architecture from scratch. Existing project research therefore cannot be used as hidden training material for the current execution.

## 2. Allowed before final KW-002 freeze

Allowed source classes:

```text
A. this KW-002 Level 1 documentation;
B. this KW-002 Level 2 step documentation;
C. this job manifest/flow/source files;
D. minimum owner/client-like business facts explicitly frozen in JOB_MANIFEST.md;
E. current raw assortment/catalog/product-list inputs supplied as client data;
F. current public marketplace/product pages used only as raw product/business facts when included in the source manifest;
G. current external methodology sources explicitly approved for the current step;
H. fresh Wordstat/Search/GenSearch evidence acquired during this KW-002 job under its own provenance.
```

## 3. Sealed / prohibited before final freeze

Do not open or use as execution inputs any prior Blood & Sand analytical artifacts containing conclusions from earlier research, including equivalents of:

```text
prior Wordstat reports/tables
prior query/opportunity maps
prior Search/SERP research
prior Alice/AI research
prior competitor analysis
prior buyer-research conclusions
prior SEO priorities
prior cluster/page decisions
prior IA/Page Jobs
prior semantic recommendations
prior conclusions copied into another repository/test
```

Specific file names do not need to be enumerated here; the rule is class-based so renamed/copy files remain prohibited.

## 4. Raw business facts vs old analysis

Allowed:

```text
product name
SKU
current product title
material/dimensions/features stated in current product data
current marketplace URL
actual product family supplied by owner/catalog
region/business operations supplied by owner
```

Not allowed before final freeze:

```text
"this product family is SEO priority"
"this query is strong/weak"
"this is a competitor"
"this should be a separate page"
"Alice wants a hybrid page"
"this cluster was previously accepted"
```

Those are analytical conclusions and must be re-earned.

## 5. Clean-context requirement

Any clean new conversation or ChatGPT Work execution used for this rehearsal receives a whitelist of allowed paths/files.

```text
DEFAULT = DENY OLD BLOOD_SAND RESEARCH
```

If a needed raw business fact currently exists only inside a mixed research artifact, do not open the mixed artifact as a shortcut. Materialize the fact independently from a current raw source or owner statement first.

## 6. After final freeze

Only after Step 20 has frozen the new KW-002 result may prior Blood & Sand research be opened for a separate regression comparison.

The comparison must record that the prior work was opened **after** the new result freeze and must not rewrite the already frozen baseline without explicit correction/versioning.
