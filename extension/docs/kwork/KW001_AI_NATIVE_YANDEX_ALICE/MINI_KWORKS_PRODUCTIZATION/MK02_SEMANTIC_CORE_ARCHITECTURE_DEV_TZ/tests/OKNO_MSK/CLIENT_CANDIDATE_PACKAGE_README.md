# OKNO_MSK — как пользоваться кандидатным пакетом

Статус: **кандидат для проверки удобства; не замороженный коммерческий шаблон**

## Что открыть первым

Откройте файл `OKNO_MSK_MK02_CLIENT_CANDIDATE_2026-09-10.xlsx` и начните с листа **«Начните здесь»**. Затем:

1. **«Главные выводы»** — что показало исследование;
2. **«ТЗ на доработку»** — что действительно готово к выполнению и что пока не готово;
3. **«Карта страниц»** — какой запрос имеет точного владельца, владельца семейства или только поддерживающую страницу;
4. **«Проверить и HOLD»** — какие факты или места размещения нужно уточнить;
5. **«Все запросы»** — полный сохранённый набор, включая спорные и исключённые строки.

## Что означает статус задания

| Статус | Практический смысл |
|---|---|
| Готово к внедрению | достаточно доказательств, чтобы выполнить описанное изменение и принять его по указанному критерию |
| Нужна бизнес-деталь | страница и задача понятны, но нельзя публиковать неподтверждённый состав услуги |
| Нужно точное место | связь по смыслу принята, но блок/абзац размещения ещё не доказан |
| Только перепроверка | разрушительное или контентное действие пока не разрешено |
| Только карта | аналитическое назначение страницы; изменения сайта не требуется |
| Без изменения | полезный результат — сохранить текущее решение |
| Отложено до доказательства | действие запрещено до появления названного доказательства |

## Важная граница

Номер строки или технический идентификатор не является очередностью производства. Ответственный, трудоёмкость, ёмкость команды и календарный срок не предоставлены и не выдумывались.

Точный владелец запроса, владелец семейства, поддерживающая страница и URL, увиденный в выдаче, — разные поля. Пустой точный URL означает отсутствие достаточного доказательства, а не автоматическое решение создать новую страницу.

## Предлагаемый физический пакет для следующего этапа

Фактический объём репетиции поддерживает следующий кандидат:

- один XLSX как рабочий файл для фильтрации и внедрения;
- один короткий управленческий PDF/DOCX, собранный из аналитического отчёта и плана действий;
- без отдельной книги на каждую роль и без копии полного технического происхождения данных в клиентском рассказе.

Рекомендация ещё не является коммерчески замороженным стандартом. На следующем этапе нужно проверить визуальную длину управленческого документа и удобство XLSX на реальном получателе.
