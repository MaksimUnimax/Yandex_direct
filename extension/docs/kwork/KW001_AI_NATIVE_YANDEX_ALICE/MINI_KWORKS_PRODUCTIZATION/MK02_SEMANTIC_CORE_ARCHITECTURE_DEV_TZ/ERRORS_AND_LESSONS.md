Status: **ACTIVE PHASE-3 FAILURE LEDGER / LEVEL 1 ONLY**

This ledger records failure classes that can materially break MK02. Concrete client URLs, phrases, counts, action IDs and provider results remain Level 2.

```text
ONE BAD EXAMPLE FIXED != FAILURE CLASS CLOSED
```

## H. Client-analytical-report lesson inherited from MK01

MK02 has both analytical and implementation-facing output layers. Therefore it inherits:

```text
CLIENT REPORT != EXECUTION PROTOCOL
CORRECT COUNTS + CLEAN LAYOUT != ANALYTICAL REPORT PASS
```

The analytical explanation must tell the client what the research found about demand/page responsibility/architecture. The implementation report must tell the client what to change, why, where/how when resolved, what needs clarification, and how to check the finished state.

Neither document may become a repository chronology.
