## 4. Product implications

The market evidence supports selling a combined outcome rather than only a keyword file:

```text
SEMANTIC DEMAND
→ CLUSTERS / USER TASKS
→ PAGE RESPONSIBILITY
→ TARGET SITE STRUCTURE
→ CONCRETE IMPLEMENTATION TASKS
```

But MK02 must distinguish itself from shallow bundle offers by making implementation readiness explicit and evidence-based.

The developer-facing output must not merely say:

- create page X;
- optimize page Y;
- distribute keywords;
- add internal links;
- improve structure.

A ready change requires exact current object/page, reason/evidence, target state, implementation mode/location when material, dependencies/preservation constraints and observable acceptance.
