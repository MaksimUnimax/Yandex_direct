# MK01 STEP 08 — TARGETED ORDINARY YANDEX SEARCH

## PURPOSE
Resolve only material semantic/intent/result-compatibility boundaries that persisted evidence cannot settle safely.

## WHY THIS STEP EXISTS
KW-001 established that exact Search observations are powerful but easy to overgeneralize, and normalized projections can be mistaken for raw evidence.

## INPUTS
Frozen semantic authority + explicit SEARCH_REQUIRED routing manifest.

## REQUIRED EVIDENCE
For each selected case: exact query, primary region/surface, observation time, preserved result evidence/projection state and the exact unresolved question.

## METHOD
Probe only selected Search-resolvable cases in ordinary Yandex Search. Preserve exact observed result pattern and claim scope. Record whether evidence resolves, de-risks or leaves the row unresolved. If no material Search route exists, mark step NOT_REQUIRED.

## OUTPUTS
Bounded exact-query Search evidence overlay + updated semantic resolution state.

## SOURCE KW-001 AUTHORITY
Step9 narrow non-repeat controls in source method ledger/index.

## KNOWN FAILURE CLASSES
E16 exact observation generalized to family; E17 normalized Search projection treated as raw.

## ROOT CAUSES
A bounded observation was promoted into broader evidence than acquired; convenient normalized data was called raw.

## NON-REPEAT CONTROLS
Exact-query claim stays exact unless an explicit supported family generalization is declared; raw/projection state always recorded; no bulk rank tracking.

## CLAIM BOUNDARIES
Search evidence supports the disputed semantic boundary only. MK01 does not promise ranking audit, page ownership, cannibalization or architecture.

## UNKNOWN / BLOCKER BEHAVIOR
Unavailable/ambiguous Search evidence keeps the case REVIEW/HOLD. Do not force a cluster decision merely because Search was attempted.

## PASS GATE
Every Search call has a routed question; exact scope/provenance preserved; no overgeneralization; all selected cases receive explicit outcome or remain unresolved.

## CLIENT-FACING MEANING
«Если по самой фразе непонятно, что именно ищет пользователь, точечно смотрю обычную выдачу Яндекса. Это не проверка позиций всего сайта, а способ аккуратно разделить спорные смыслы.»
