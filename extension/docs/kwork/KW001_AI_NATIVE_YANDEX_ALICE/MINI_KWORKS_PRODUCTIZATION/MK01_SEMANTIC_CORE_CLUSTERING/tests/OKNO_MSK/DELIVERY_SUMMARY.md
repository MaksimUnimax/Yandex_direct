# Семантическое ядро сайта okno-msk.ru

Регион исследования: **Москва**  
Источник спроса: **Яндекс Вордстат, все устройства, без операторов**  
Результат: **сбор, очистка и смысловая группировка запросов**

## Что подготовлено

В исследовании сохранено **2840 уникальных поисковых фраз** из **2965 исходных наблюдений Вордстата**. Повторные наблюдения не сложены и не потеряны: они остались в происхождении данных.

После построчной очистки, точечных проверок ранее сохранённой обычной выдачи Яндекса и группировки по задаче пользователя получено:

| Часть результата | Фраз |
|---|---:|
| Рабочее семантическое ядро | **2185** |
| На дополнительную проверку | **187** |
| Исключено с сохранением причины | **468** |
| Полный сохранённый набор | **2840** |

Фразы распределены по **59 смысловым группам**: 54 рабочие группы и 5 групп с подтверждённо посторонней для текущего предложения задачей. Эти 5 групп содержат 134 фразы и показаны среди исключённых, а не подмешаны в рабочее ядро.

## С чего начать

Откройте файл `MK01_OKNO_MSK_SEMANTIC_CORE_2026-09-09.xlsx` и начните с листа **«Рабочее ядро»**. Для понимания структуры групп используйте лист **«Группы запросов»**. Спорные и отложенные решения находятся на листе **«На проверку»**, а все исключения вместе с причиной — на листе **«Исключено»**.

Показатель «число запросов» помогает сравнивать формулировки внутри исследования. Он получен из широкого Вордстат-сбора без операторов и поэтому не является точной частотностью фразы, числом уникальных пользователей или прогнозом трафика.

## Граница результата

Это самостоятельный результат MK01. В него не добавлены 16 фраз из последующего анализа конкурентов. В файле нет назначения запросов конкретным URL, проекта новой архитектуры, рекомендаций по созданию или объединению страниц, перелинковки, контентных заданий, данных Google или выводов из ИИ-ответов.

Коммерческий приоритет групп нельзя определить только по спросу: для этого нужны данные клиента о маржинальности, конверсии, загрузке производства и стратегических приоритетах.
