# OKNO_MSK — CLIENT HANDOFF PACKAGE EXAMPLE

Status: **FINAL CLIENT PACKAGE EXAMPLE / XLSX + PDF**

Этот файл показывает, как фактически проверенный OKNO_MSK результат передаётся клиенту в границах только MK01. Это rehearsal example, а не универсальные коммерческие лимиты.

## Что отправляется клиенту

Два клиентских файла:

1. `MK01_OKNO_MSK_SEMANTIC_CORE_2026-09-09.xlsx` — рабочее семантическое ядро.
2. `MK01_OKNO_MSK_CLIENT_REPORT_2026-09-09.pdf` — 6-страничный итоговый отчёт с объяснением работы и результата.

Клиентская поставка не требует репозитория, audit TSV.GZ, cluster TSV, manifest, machine-QA JSON, build receipts или внутренних Stage/Step материалов.

## Готовое сообщение передачи

Здравствуйте!

Готово семантическое ядро для сайта **okno-msk.ru** по региону **Москва**.

В рамках работы собраны поисковые формулировки по согласованным направлениям, проверен сохранённый спрос Яндекс Wordstat, удалены подтверждённо нерелевантные запросы, спорные формулировки сохранены отдельно, а рабочая семантика сгруппирована по смыслу и задаче пользователя. Для отдельных неоднозначных случаев использовались ранее сохранённые точечные проверки обычной выдачи Яндекса.

### Результат

- исходных Wordstat-наблюдений: **2965**;
- уникальных сохранённых фраз: **2840**;
- рабочее семантическое ядро: **2185**;
- на дополнительную проверку: **187**;
- исключено с сохранением причины: **468**;
- смысловых групп: **59**;
- рабочих групп: **54**.

К сообщению приложены:

- **MK01_OKNO_MSK_CLIENT_REPORT_2026-09-09.pdf** — сначала рекомендую прочитать этот короткий отчёт;
- **MK01_OKNO_MSK_SEMANTIC_CORE_2026-09-09.xlsx** — основной рабочий файл. После отчёта начните с листов **«Как пользоваться»** и **«Рабочее ядро»**.

В Excel лист **«Группы запросов»** показывает смысловую структуру ядра. Спорные запросы вынесены в **«На проверку»**, исключённые запросы вместе с причиной — в **«Исключено»**, а лист **«Все запросы»** сохраняет полный набор исследования.

Показатель «число запросов» получен из широкого Wordstat-сбора без операторов. Он полезен для сравнения формулировок внутри исследования, но не является точной частотностью конкретной фразы, числом уникальных пользователей или прогнозом трафика.

Работа выполнена по поисковому спросу **Яндекса**. Данные Google в результат не входят.

В этот результат не входят назначение запросов конкретным URL, проект новой SEO-архитектуры, рекомендации по созданию/объединению страниц, конкурентный gap-анализ, ТЗ разработчику и анализ Алисы/Яндекс Нейро.
