# Отчёт по семантическому ядру

**Сайт:** okno-msk.ru  
**Регион:** Москва  
**Поисковая система:** Яндекс  
**Источник спроса:** Яндекс Вордстат

## Ключевой результат

- Сохранено уникальных фраз: **2 840**
- Рабочее ядро: **2 185**
- На проверку: **187**
- Исключено: **468**
- Смысловых групп: **59** (54 рабочих + 5 с посторонней задачей)

Рабочие запросы распределены по смысловым группам. Пять групп с посторонней задачей сохранены в аудите, но не подмешаны в рабочее ядро.

## 1. Что исследовали

Исследование выполнено для действующего коммерческого сайта okno-msk.ru в Москве. Цель — собрать поисковые формулировки по подтверждённым направлениям бизнеса, очистить нерелевантный спрос и сгруппировать рабочие запросы по смыслу и задаче пользователя.

Исследовались пластиковые окна и REHAU, окна по применению/форме/типу дома, пластиковые двери, балконы и лоджии, веранды/террасы/беседки, алюминиевые окна, аксессуары, установка/ремонт/обслуживание, цены/рассрочка и информационный спрос о выборе окон.

## 2. Как выполнена работа

1. Зафиксированы сайт, регион и направления.
2. Собран спрос через Яндекс Вордстат с сохранением исходных наблюдений.
3. Проведена очистка; спорные запросы не удалялись молча.
4. Для части неоднозначных формулировок использованы точечные наблюдения обычной выдачи Яндекса.
5. Рабочие запросы сгруппированы по пользовательской задаче, а не только по одинаковым словам.
6. Подготовлены рабочий Excel и итоговый отчёт.

## 4. Примеры смысловых групп

- **Алюминиевые окна** — 100 рабочих фраз. Задача: выбрать и заказать алюминиевые окна. Примеры: «алюминиевые окна», «алюминиевые раздвижные окна», «купить алюминиевые окна», «алюминиевые окна Москва».
- **Аксессуары для окон** — 47 рабочих фраз. Задача: выбрать и купить дополнительные элементы. Примеры: «откосы для пластиковых окон», «створка пластикового окна», «подоконник для пластиковых окон».
- **Замена окон** — 23 рабочих фразы. Задача: заказать полную замену окон.
- **Как выбрать окна** — 20 рабочих фраз. Задача: получить помощь в выборе окна или системы.

География, цена, бренд, тип здания или отдельное слово не создают новую группу автоматически. Разделение выполняется, когда меняется задача пользователя или ожидаемый результат поиска.

## 5. Как пользоваться Excel-файлом

Рекомендуемый порядок: «Как пользоваться» → «Рабочее ядро» → «Группы запросов» → «На проверку» → «Исключено» → при необходимости «Все запросы» и «Методика».

Широкий сбор Вордстат выполнен без операторов. Поэтому показанное число запросов помогает сравнивать формулировки внутри исследования, но не является точной частотностью конкретной фразы, числом уникальных пользователей или прогнозом трафика.

## 6. Ограничения

Работа выполнена по Яндексу. Google Ads, Google Keyword Planner, Google Search Console и выдача Google не входили. Результат не назначает запросы URL, не проектирует SEO-архитектуру, не даёт ТЗ на внедрение, не включает конкурентный gap-анализ или анализ Алисы/Яндекс Нейро и не гарантирует позиции/трафик/продажи.
