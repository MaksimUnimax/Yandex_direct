# MK01 — CLIENT HANDOFF TEMPLATE

Status: **REUSABLE CLIENT-FACING DELIVERY TEMPLATE**

Этот шаблон заполняется только фактическими результатами текущего заказа после QA. Значения из OKNO_MSK не копируются в новый заказ.

---

## Шаблон сообщения клиенту

Здравствуйте!

Готово семантическое ядро для сайта **[САЙТ]** по региону **[РЕГИОН]**.

В рамках работы я собрал поисковые формулировки по согласованным направлениям, проверил спрос через Яндекс Wordstat, очистил нерелевантные запросы, отдельно сохранил спорные формулировки и сгруппировал рабочую семантику по смыслу и задаче пользователя. Для неоднозначных случаев использовалась точечная проверка обычной выдачи Яндекса, если она действительно требовалась для решения.

### Результат

- сохранено уникальных фраз: **[ВСЕГО_ФРАЗ]**;
- рабочее семантическое ядро: **[РАБОЧЕЕ_ЯДРО]**;
- оставлено на дополнительную проверку: **[НА_ПРОВЕРКУ]**;
- исключено с сохранением причины: **[ИСКЛЮЧЕНО]**;
- смысловых групп: **[ГРУПП_ВСЕГО]**;
- рабочих групп: **[РАБОЧИХ_ГРУПП]**.

Основной файл: **[ИМЯ_XLSX]**.

Начните с листа **«Как пользоваться»**, затем переходите к **«Рабочему ядру»**. Лист **«Группы запросов»** показывает смысловую структуру ядра. Спорные формулировки вынесены в **«На проверку»**, а исключённые запросы и причины — в **«Исключено»**. Лист **«Все запросы»** сохраняет полный набор исследования.

### Важно о показателях Wordstat

Показатель Wordstat нужно трактовать в соответствии с режимом сбора. Если использовался широкий сбор без операторов, число помогает сравнивать спрос внутри исследования, но не является точной частотностью конкретной фразы, количеством уникальных пользователей или прогнозом трафика.

### Граница работы

Работа выполнена по поисковому спросу **Яндекса**. Google Ads, Google Keyword Planner, Google Search Console и исследование выдачи Google в результат не входят.

В этот результат также не входят готовое назначение запросов конкретным страницам, проект новой SEO-структуры сайта, рекомендации по созданию/объединению страниц, конкурентный gap-анализ, ТЗ разработчику и анализ Алисы/Яндекс Нейро. Это отдельные задачи и отдельные продукты.

Если вам нужно использовать ядро дальше, основной рабочий набор находится на листе **«Рабочее ядро»**, а спорные запросы лучше не смешивать с ним до отдельной проверки.
