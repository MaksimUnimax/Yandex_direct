# MK01 — PORTFOLIO / KWORK VISUAL SPEC

Status: **PHASE 10 ASSET SPEC READY / VISUAL GENERATION NEXT**

## 1. Main Kwork cover

Purpose: the buyer must understand the service in 1–2 seconds on a small marketplace card.

Format: horizontal marketplace cover, target composition 3:2, important text kept inside the central safe area.

### Exact public text

Primary headline:

**СЕМАНТИЧЕСКОЕ ЯДРО**

Secondary line:

**Сбор • чистка • кластеризация**

Capacity badge:

**до 1500 запросов**

Evidence badge:

**Яндекс Wordstat**

Do not add price to the image; price is rendered by Kwork and may be versioned independently.

### Visual language

- professional SEO/data-research look;
- light/clean background;
- one strong red accent associated with Yandex context without copying the Yandex logo;
- spreadsheet/table fragment + grouped keyword chips/nodes;
- visually show movement from many raw queries into clean semantic groups;
- high contrast, large typography, mobile-readable;
- no generic stock-photo person;
- no 3D corporate handshake imagery;
- no tiny unreadable text;
- no fake charts or invented business-growth percentages;
- no ranking arrows / TOP-1 promises;
- no Google marks.

## 2. Optional portfolio proof image

This is separate from the main cover and may be produced after the cover is accepted.

Public heading:

**Как выглядит результат**

Public case label:

**Пример на действующем коммерческом сайте**

Safe anonymized case metrics from the validated rehearsal:

```text
2840 уникальных запросов обработано
2185 — рабочее ядро
187 — оставлено на проверку
468 — исключено с причиной
59 смысловых групп

```

Allowed explanation:

**Запросы не просто выгружаются из Wordstat: они очищаются, проверяются и распределяются по смысловым группам. Спорные и исключённые фразы сохраняются отдельно.**

Do not disclose:

- OKNO_MSK name/domain;
- repository paths;
- Stage/Step IDs;
- provider IDs;
- internal failure classes;
- client-sensitive details;
- architecture/query→URL conclusions from larger KW-001 products.

## 3. Visual QA

PASS only when:

```text
SERVICE READABLE AT THUMBNAIL SIZE
+ MAIN HEADLINE EXACT
+ NO SPELLING ERRORS
+ NO GOOGLE
+ NO PRICE ON IMAGE
+ NO RANKING / TRAFFIC GUARANTEE
+ NO INTERNAL IDs
+ NO CLIENT NAME/DOMAIN
+ VISUAL MATCHES SEMANTIC-CORE PRODUCT
```

If generated text is misspelled or visually garbled, regenerate/correct rather than publishing it.

## 4. Phase boundary

Phase 10 is not PASS merely because this spec exists. It reaches PASS only after a usable public visual is generated/reviewed. Owner publication remains Phase 11.
