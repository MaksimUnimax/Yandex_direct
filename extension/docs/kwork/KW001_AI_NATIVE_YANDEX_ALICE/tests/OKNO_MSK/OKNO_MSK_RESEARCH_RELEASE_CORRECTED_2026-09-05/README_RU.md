# OKNO_MSK — исправленный получательский комплект

Дата: 2026-09-05

Этот каталог заменяет получательские документы №01-03 предыдущего выпуска и содержит отдельное рабочее семантическое ядро. Исторический каталог выпуска сохранён как provenance и не переписан.

1. `01_OKNO_MSK_CLIENT_RESEARCH_REPORT_RU_2026-09-05.pdf` — полный русский отчёт для владельца; editable-копия в `editable/`.
2. `02_OKNO_MSK_SEO_IMPLEMENTATION_GUIDE_RU_2026-09-05.pdf` — русское исполнимое руководство специалиста: семь готовых изменений, одна частичная работа, отдельные реестры семантических назначений, проверок и потенциальных ссылок; editable-копия в `editable/`.
3. `03_OKNO_MSK_AI_KNOWLEDGE_DOCUMENT_2026-09-05.md` — единственный физический документ №03. Companion-файлов у №03 нет.
4. `04_OKNO_MSK_FULL_SEMANTIC_CORE_2026-09-07.xlsx` — отдельное машиночитаемое семантическое ядро для фильтрации, кластеризации, назначения страниц, приоритизации и последующей SEO-работы; оно не встроено в №02.

Документы материализованы из одной текущей семантической и реализационной власти. AI-файл объясняет исследование, но не предоставляет CMS/серверный доступ и не утверждает физическое изменение сайта.

Как пользоваться комплектом:

- №01 читать владельцу для полного понимания исследования, доказательств, правильных решений, изменений и ограничений;
- №02 передать SEO-специалисту: семь пронумерованных готовых изменений являются самостоятельными задачами, а нумерация нужна только для навигации и приёмки; фактическую очередность определяют с учётом трудоёмкости, ресурсов и зависимостей. Частичную работу выполнять только в прямо разрешённой части; семантические назначения, вопросы на проверку и потенциальные ссылки не считать скрытыми задачами на изменение сайта;
- №03 загрузить в совместимую локальную или отдельную AI-модель как единственный контекст: второй файл, интернет, GitHub, workbook, №01 или №02 не требуются.
- №04 использовать SEO-специалисту как рабочую таблицу: основная работа ведётся на листе `02_Активное_ядро`, а листы кластеров, страниц, `05_Проверка_в_Яндексе` и справочник объясняют группировку и ограничения. Названия листов, основные заголовки, статусы, действия и пояснения даны по-русски; технические коды вынесены в справочник. Значение — статистика раздела «Топы запросов» Вордстата по Москве, для всех устройств, без операторов; это не точная частотность фразы и не прогноз трафика.

Хэши, размеры, роли и границы проверки зафиксированы в `RELEASE_MANIFEST_2026-09-05.json`. После первого аналитического PASS владелец вернул документ №02 на вторую коррекцию. Вторая коррекция устранила внутренние идентификаторы и имена файлов, общие шаги, неоднозначные места, незавершённую классификацию портфолио, заполнитель даты, повтор видимой пары ссылок и пробел по источникам Алисы. Повторная аналитическая проверка пройдена; приёмка владельцем остаётся открытой. Документ №03 не продолжать до отдельного решения владельца.
