# OKNO_MSK — исправленный получательский комплект

Дата: 2026-09-05

В комплект входят четыре результата:

1. `01_OKNO_MSK_CLIENT_RESEARCH_REPORT_RU_2026-09-05.pdf` — полный русский отчёт о проведённом исследовании; редактируемая копия находится в `editable/`.
2. `02_OKNO_MSK_VNEDRENIE_REKOMENDATSII_RU_2026-09-05.pdf` — «Внедрение рекомендации»: готовые изменения, конкретные уточнения, распределение тем по страницам, проверки и связи между страницами; редактируемая копия находится в `editable/`.
3. `03_OKNO_MSK_AI_KNOWLEDGE_DOCUMENT_2026-09-05.md` — единый документ для загрузки в локальную или отдельную AI-модель.
4. `04_OKNO_MSK_FULL_SEMANTIC_CORE_2026-09-07.xlsx` — рабочее семантическое ядро с фразами, группами, страницами, проверками в Яндексе и справочником.

## Как пользоваться комплектом

- №01 — чтобы понять ход исследования, результаты, выводы и основания рекомендаций.
- №02 — чтобы внедрять рекомендации: сначала выполнить 3 готовых изменения; по 5 следующим пунктам получить указанные ответы; таблицу распределения тем использовать при подготовке и обновлении материалов; 4 проверки провести перед следующими решениями; 14 направлений между страницами использовать при подготовке внутренних переходов.
- №03 — загрузить в AI-модель как единый контекст исследования.
- №04 — использовать как полный рабочий набор поисковых фраз и их распределения по группам и страницам.

Статистика спроса в №04 — данные раздела «Топы запросов» Вордстата по Москве, для всех устройств, без операторов; она используется для относительного сравнения спроса внутри исследования.

Хэши и размеры файлов зафиксированы в `RELEASE_MANIFEST_2026-09-05.json`. Приёмка документа №02 владельцем остаётся открытой.
