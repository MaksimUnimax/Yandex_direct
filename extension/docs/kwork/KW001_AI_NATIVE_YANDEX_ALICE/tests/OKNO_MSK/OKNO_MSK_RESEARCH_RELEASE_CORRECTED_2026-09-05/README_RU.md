# OKNO_MSK — исправленный получательский комплект

Дата: 2026-09-05

В комплект входят четыре результата:

1. `01_OKNO_MSK_CLIENT_RESEARCH_REPORT_RU_2026-09-05.pdf` — полный русский отчёт для владельца; editable-копия находится в `editable/`.
2. `02_OKNO_MSK_SEO_IMPLEMENTATION_GUIDE_RU_2026-09-05.pdf` — руководство для SEO-специалиста, редактора и разработчика; editable-копия находится в `editable/`.
3. `03_OKNO_MSK_AI_KNOWLEDGE_DOCUMENT_2026-09-05.md` — единый документ для загрузки в локальную или отдельную AI-модель.
4. `04_OKNO_MSK_FULL_SEMANTIC_CORE_2026-09-07.xlsx` — рабочее семантическое ядро для фильтрации, кластеризации, назначения страниц и дальнейшей SEO-работы.

## Как пользоваться комплектом

- №01 — для владельца: ход исследования, результаты, выводы, изменения и ограничения.
- №02 — для специалиста: 3 готовых изменения, 5 пунктов для уточнения, 46 семантических назначений, 4 дополнительные проверки и 14 внутренних связей для детализации.
- №03 — для AI-модели как единый контекст исследования.
- №04 — рабочая таблица специалиста. Основная работа ведётся на листе `02_Активное_ядро`; остальные листы показывают кластеры, страницы, проверки в Яндексе и справочник.

Статистика спроса в №04 — данные раздела «Топы запросов» Вордстата по Москве, для всех устройств, без операторов; она используется для относительного сравнения спроса внутри исследования.

Хэши, размеры и роли файлов зафиксированы в `RELEASE_MANIFEST_2026-09-05.json`. Документ №02 прошёл повторную аналитическую и визуальную проверку; приёмка владельцем остаётся открытой.
