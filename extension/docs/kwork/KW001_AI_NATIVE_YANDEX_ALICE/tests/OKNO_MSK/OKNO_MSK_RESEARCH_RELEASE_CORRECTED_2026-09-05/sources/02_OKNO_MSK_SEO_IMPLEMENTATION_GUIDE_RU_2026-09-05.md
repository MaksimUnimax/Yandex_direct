## 1. Сначала определите тип строки

- `CONTENT_BLOCK`: физическая правка содержания существующей страницы; `REAL_SITE_CHANGE = YES`.
- `NAVIGATION_CHANGE`: физическое изменение навигации внутри конкретной страницы; `YES`.
- `SEMANTIC_MAPPING_ONLY`: назначение владельца/поддержки только в семантической и контентной карте; `NO`.
- `RECHECK_ONLY`: вопрос для проверки; текущей правки сайта нет.
- `CONTEXTUAL_LINK`: потенциальная ссылка. READY только при доказанном source-блоке, контексте, анкорном смысле и проверке.
- `NO_SITE_CHANGE`: положительный запрет на отдельную правку.
- `HOLD`: внедрение запрещено до нового доказательства.
