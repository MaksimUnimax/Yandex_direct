# Руководство по внедрению изменений на сайте okno-msk.ru

Документ №02 для SEO-специалиста, редактора и разработчика

## 1. Как пользоваться руководством

Этот документ содержит только действия и ограничения, необходимые для внедрения. Выполняйте семь готовых пунктов по порядку их нумерации; каждый пункт можно принять отдельно.

Полное семантическое ядро находится в книге `04_OKNO_MSK_FULL_SEMANTIC_CORE_2026-09-07.xlsx`. В документе №02 приведены только темы и примеры, которые нужны для выполнения работ; полный состав фраз, кластеров, страниц и частотности следует смотреть в листах `02_Активное_ядро`, `03_Кластеры` и `04_Страницы` книги №04.

Пункты из разделов «Нужна дополнительная проверка» и «Потенциальные внутренние ссылки» сейчас внедрять нельзя. Семантическое назначение страницы означает правило для ядра и контент-планирования, а не автоматическую правку сайта.

## 2. Как получен план внедрения

Сначала была зафиксирована текущая структура сайта и публично подтверждаемый объём услуг. Затем Вордстат дал 2 415 строк первого сбора и 550 строк целевого расширения: 2 965 наблюдений до удаления повторов и 2 840 уникальных формулировок. После очистки осталось 2 332 активные фразы; 2 313 получили финальное назначение, ещё 19 требуют дополнительной проверки в обычном поиске Яндекса.

Активные фразы сгруппированы в 168 пользовательских задач и сопоставлены с существующими страницами. Для спорных мест сохранены 75 наблюдений обычной выдачи Яндекса. В восьми отдельных случаях результат сравнивался с выдачей Алисы: это помогло подтвердить, уточнить или ограничить решение, но не заменяло исследовательский анализ.

После сопоставления были отдельно выделены физические изменения сайта, частично подтверждённое изменение, аналитические назначения, вопросы без достаточных доказательств и потенциальные внутренние ссылки.

Статистика спроса в исследовании взята из раздела «Топы запросов» Вордстата по Москве, для всех устройств, без операторов. Она используется для относительного сравнения спроса и не является точной частотностью конкретной фразы или прогнозом трафика. Подробные значения находятся в книге №04.

Усилить существующую страницу французских окон: конфигурации, замена балконного блока и ясное отличие французского решения от общего панорамного остекления.

Не обещать возможность изменения проёма без замера и согласования; не создавать новый URL; не дублировать базовое определение отдельным блоком.

**Что именно изменить**

Сделать портфолио навигируемым по подтверждённым типам работ: балконы, веранды, панорамные и французские решения, материал и режим использования.

**Где именно изменить**

Над списком или сеткой работ.

**Пошагово**

1. Откройте указанную страницу и найдите обозначенный блок.
2. Сохраните полезные элементы, перечисленные ниже.
3. Добавьте или измените материал в указанном месте, не меняя роль страницы.
4. Сверьте формулировки с ограничениями: неподтверждённые факты не публикуются.
5. Проверьте результат по критериям приёмки этого пункта.

**Как это может выглядеть**

Пример смысловой реализации, а не цитата текущей страницы:

> Над работами разместить доступный список фильтров: **«Балконы», «Веранды», «Панорамное остекление», «Французские решения», «Алюминиевые конструкции», «Тёплое / холодное остекление»**. Для каждой карточки показывать только реально подтверждённые признаки; предусмотреть возврат к полному списку.

**Что обязательно сохранить**

Все существующие карточки работ, их изображения, ссылки и возможность просмотра полного списка.

**Чего нельзя добавлять / утверждать**

Не создавать пустые категории и не присваивать работе тип, который нельзя подтвердить по карточке.

**Как проверить выполнение**

- Семантические назначения не должны превращаться в скрытые задания на изменение сайта.
- Отсутствие доказанного вреда пересечения означает сохранение структуры, а не разрешение на «профилактическое» объединение страниц.
