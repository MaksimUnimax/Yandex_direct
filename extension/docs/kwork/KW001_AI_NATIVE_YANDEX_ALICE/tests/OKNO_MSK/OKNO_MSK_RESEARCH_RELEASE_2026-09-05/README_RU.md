## Что должен представлять файл №03 после исправления

Файл №03 нужен для **передачи результатов выполненного исследования другой AI-системе**.

Правильный сценарий: пользователь загружает основной AI knowledge document в новый чат / новую AI-систему, а затем даёт конкретную новую задачу, для которой нужны результаты этого исследования. AI должен получить из одного документа достаточный контекст о том, что исследовалось, какие evidence использовались, какие решения приняты и почему, что подтверждено, что рекомендовано, что осталось неопределённым и какие выводы делать нельзя.

Файл №03 **не является** execution cursor, roadmap handoff, checkpoint или автоматической инструкцией продолжать внутреннюю работу проекта.

Исправленный основной физический формат №03: **Markdown (`.md`) как LLM-readable knowledge/context document**. JSON может сохраняться только как дополнительное структурированное data-приложение, если он нужен для полного row-level набора, но не как автоматическая замена основного AI handoff.

```text
AI RESEARCH KNOWLEDGE HANDOFF
!= INTERNAL EXECUTION HANDOFF

MACHINE-READABLE
!= LLM-USABLE
```

## Как использовать исправленный №03

1. Загрузить основной `.md` AI knowledge document в новую AI-сессию.
2. Указать AI использовать его как самодостаточный контекст результатов исследования.
3. Дать конкретную новую пользовательскую задачу.
4. AI использует зафиксированные выводы/evidence/boundaries и не домысливает отсутствующие факты.

Новый AI не должен самостоятельно восстанавливать Stage/Step, `EXECUTION_CURSOR`, внутреннюю review queue или автоматически выполнять следующий этап только потому, что документ был загружен.
