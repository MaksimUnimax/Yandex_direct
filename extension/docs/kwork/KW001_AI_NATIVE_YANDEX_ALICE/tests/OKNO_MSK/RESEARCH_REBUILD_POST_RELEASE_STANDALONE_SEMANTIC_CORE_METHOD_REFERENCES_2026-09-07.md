## Применённые проектные правила

1. Финальная семантика, структурная единица, интент, бизнес-граница, URL, действие, зрелость и неопределённость берутся только из Stage-5.
2. Wordstat result/association counts и provenance присоединяются из Step-08 по нормализованной точной строке фразы.
3. Broad `getTop` counts используются для грубой сортировки, рангов внутри уже принятого кластера/страницы и выбора репрезентанта; они не суммируются как уникальный рынок.
4. Русское имя кластера равно проверенной репрезентативной фразе из самого кластера. Внутренний `structural_unit_id` сохраняется отдельно и не переводится эвристически.
5. Отсутствующий Stage-5 URL не заполняется. В книге выводится управляемая причина: `NO_STANDALONE_PAGE`, `OUTSIDE_SCOPE_NO_ACTION`, `DEFER_PENDING_EVIDENCE` или `SEARCH_REQUIRED`.
6. Операционный приоритет объясняется через статус, действие, зрелость, неопределённость и broad-спрос. Это не оценка маржинальности, выручки или внутренней бизнес-ценности.
