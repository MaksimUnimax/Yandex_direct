## 1. Test role

This is a mock commercial order used to rehearse the complete KW-001 workflow on a real public commercial site.

The site is not represented as an actual paying client. Any portfolio artifact derived from this run must be labeled clearly as a test/demo case.

## 2. Initial reconnaissance disclosure

Before this order freeze, a limited accessibility reconnaissance was performed only to confirm that the public site can be read from the current ChatGPT web environment.

Pages surfaced during that reconnaissance included the homepage plus public pages such as contacts, delivery/payment, production and installation. This is logged so the test does not pretend to be a pristine blind pre-analysis experiment.

No Wordstat, ordinary Yandex Search, Search batch or GenSearch provider evidence for the mock order has been acquired before this freeze.

## 4. Public business facts allowed at intake

Only obvious public facts observed during accessibility reconnaissance are frozen as intake context:

- site markets plastic/PVC windows in Moscow;
- site presents REHAU profile systems;
- company presents manufacturing + installation capability;
- visible commercial families include windows, doors, balconies/loggias, verandas and aluminium windows;
- site contains calculator/price/action/contact conversion paths;
- site presents existing content around production, installation, delivery/payment and related commercial/service information.

These facts are intake context, not SEO conclusions.

## 5. Mock client goals

Assume the client asks:

1. Which existing commercial directions/pages should remain primary landing pages?
2. Which query families are currently mixed together and should be split or reassigned?
3. Which informational/selection jobs are important enough to influence commercial page architecture?
4. Where does ordinary Yandex Search suggest one page job but AI-search evidence suggests a materially different or richer job?
5. Which new pages/content layers are justified, and which would likely create thin overlap/cannibalization?
6. What should be implemented first?
