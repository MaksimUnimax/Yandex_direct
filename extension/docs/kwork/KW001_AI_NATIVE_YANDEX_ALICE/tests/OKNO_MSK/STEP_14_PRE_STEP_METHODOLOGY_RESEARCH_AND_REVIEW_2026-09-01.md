
## CURRENT EXTERNAL METHOD RESEARCH

### Official Yandex — site structure

Source:

https://yandex.ru/support/webmaster/ru/recommendations/site-structure

Current Yandex guidance states that a site should maintain a clear link structure; every document should belong to its section and should be reachable through an ordinary HTML `<a href>` link. Yandex also recommends unique URLs and text links between sections.

Method consequence:

```text
SEARCH ARCHITECTURE FREEZE
-> explicit page responsibility
-> explicit current URL
-> important pages reachable through real links
-> internal-link edges must be concrete and current
```

This source does **not** prescribe the exact KW-001 cluster taxonomy or a universal fixed crawl depth/count. Those remain project/configuration decisions.

### Official Yandex — duplicates and canonical URLs

Sources:

https://yandex.ru/support/webmaster/ru/robot-workings/double
https://yandex.ru/support/webmaster/ru/robot-workings/canonical

Yandex states that identical/similar pages may be grouped as duplicates and one page may be selected for Search. `rel="canonical"` is a recommendation for duplicate/similar-address cases and may be ignored when content differs materially.

Method consequence:

```text
CANONICAL != GENERIC ARCHITECTURE CLEANUP
DISTINCT USEFUL INTENT PAGE != DUPLICATE BY DEFAULT
```

Step 14 may carry a canonical/duplicate candidate only when accepted evidence actually supports a duplicate/near-duplicate relationship. Step 13 authorized no destructive remediation for the current job.

### Official Yandex — redirects / actual URL change

Sources:

https://yandex.ru/support/webmaster/ru/robot-workings/managing-redirects
https://www.yandex.ru/support/webmaster/ru/recommendations/changing-site-structure

Yandex recognizes `301/308` as permanent redirects. When a page address is actually changed, Yandex recommends server-side redirection from the old URL to the corresponding new URL.

Method consequence:

```text
301 = TRUE URL MOVE / CONSOLIDATION IMPLEMENTATION MECHANISM
301 != DEFAULT RESPONSE TO TOPICAL OVERLAP
```

Step 14 is a freeze/recommendation step and must not invent a redirect without an accepted move/consolidation decision.
