

Never silently relabel GenSearch observations as consumer-Alice observations.

Permanent non-equivalence:

```text
GEN_SEARCH_QUERY_OBSERVED != ALICE_FANOUT_OBSERVED
GEN_SEARCH_ANSWER != CONSUMER_ALICE_ANSWER
GEN_SEARCH_SOURCE != CONSUMER_ALICE_SOURCE
```

Priority reasons also remain distinct:

```text

A = AI importance
C = Commercial value
O = Owned-asset value
```

No unexplained combined score is required.
